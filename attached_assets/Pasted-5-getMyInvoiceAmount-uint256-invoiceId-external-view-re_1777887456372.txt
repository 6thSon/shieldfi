5. getMyInvoiceAmount(uint256 invoiceId) external view returns (euint64)
   - Returns encrypted amount — caller must have been granted access via FHE.allow()

6. regulatorDecrypt(uint256 invoiceId) — only owner, returns handle for full decryption

### CRITICAL FHEVM RULES TO FOLLOW
- NEVER use euint64 in if/require conditions directly — use FHE.select() for conditional logic on encrypted values
- ALWAYS call FHE.allowThis(encryptedValue) after storing encrypted state
- ALWAYS call FHE.allow(encryptedValue, address) for each party that needs to read it
- Use FHE.fromExternal(inputHandle, inputProof) to convert user inputs — never store externalEuint64 directly
- euint64 is the correct type for financial amounts (supports up to ~18 quintillion)
- The contract must extend ZamaEthereumConfig for Sepolia deployment
